# M7 live tailoring variant QA

This QA run validates the same locked Linen Earth mannequin with deterministic geometry-backed style changes for:
shirt fit, tucked/untucked wear, sleeve length, collar, cuff, placket, pocket,
trouser silhouette, rise, pleat, waistband and break.

The six production fabric panel materials remain contract-compatible while variant meshes use additional transparent materials that receive the same calibrated fabric texture and roughness pipeline.
