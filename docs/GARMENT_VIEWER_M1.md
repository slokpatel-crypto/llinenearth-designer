# GarmentViewer M1

## Purpose

Prove the reusable 3D path before investing in the final Linen Earth body/garment mesh.

The milestone keeps the current photographic Designer and Style Director untouched. The proof lives at `/lab/garment-viewer`; the protected public `/visual` route continues to redirect to Style Director.

## Implemented

- One reusable temporary male outfit GLB generated locally in the browser.
- Separate named `ShirtFabric` and `TrouserFabric` PBR materials.
- Real Linen Earth stock swatches can be swapped independently on shirt and trouser.
- Both garment materials stay non-metallic and expose adjustable roughness.
- A generated linen normal texture adds a small repeatable weave relief signal.
- Texture repeat scale can be changed without regenerating a person or garment.
- Four fixed camera presets: front, 3/4, side and back.
- Free mouse/touch orbit and zoom.
- Responsive controls, loading progress and error state.
- No FASHN or other generation credits.

## Temporary geometry

The M1 body and garments are deliberately block geometry. It exists to prove:

`one model -> one stable camera system -> replace garment materials -> preserve identity`

It is not a realism claim and must not replace the photographic customer preview yet.

## Runtime choice

The lab uses the pinned Google `<model-viewer>` 4.3.1 module. The actual prototype GLB is generated by Linen Earth code, so no third-party model asset is downloaded or licensed.

## Next milestone

Replace the temporary geometry with an approved Linen Earth office-wear mesh that has:

1. realistic 5'8" neutral male proportions,
2. shirt and trouser meshes fitted to the same body,
3. production UVs with measured fabric scale,
4. garment-local normal/roughness tuning,
5. fixed front / 3/4 / side / back cameras,
6. mobile performance budget,
7. visual QA against the approved photographed model reference.

The material and camera interfaces from M1 should remain stable while geometry is upgraded.
