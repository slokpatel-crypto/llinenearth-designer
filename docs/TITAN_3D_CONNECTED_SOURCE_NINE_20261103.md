## Real connected-source experiment

This branch modifies only the nonexport source research script, workflow native assertions, a Node guard, and this checkpoint. It builds two separate Blender objects, preserving the *real 2,650 original source trouser faces plus the six existing research connector triangles*:

1. **Unchanged source control:** all original source vertices and research bridge triangulation, no vertex movement.
2. **Positive +9mm source:** moves four genuine original cut-edge vertices along their actual nearest original-body surface normals. All real adjacent original trouser-source faces sharing those vertices **move with them**, rather than leaving detached patch boundaries.

Both objects are independently non-exported, invisible research meshes. The original six authored garment objects, body, closed vocabularies, locked `linen-earth-studio-model-v1` identity, original Studio reference photograph, source UV and production preview remain untouched.

Measure: real adjacent source face IDs/count, original 2-face bridge provenance, **whole source prototype and specifically affected original trouser faces** contact BVH pairs and measured area against the actual original body, seven near-body distances on each moved cut edge, original source topology boundary count, source adjacent face normal reversals and bounded actual vertex displacement. Positive candidate is NOT declared better if it increases adjacent source body contact or flips face normals.

**Limitations:** This approach might introduce collision/inversion in neighboring original source trouser faces. It is NOT a sewn manifold; source body-shell offsets are not the tailored trouser pattern; no UV seam solution, cloth thickness or supplier textile measurement, photo-fidelity, tailor fit or four-angle QA.
